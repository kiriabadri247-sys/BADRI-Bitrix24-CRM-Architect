# REST API

Назначение: знания о методах, ограничениях и безопасных шаблонах работы с Bitrix24 REST API.

Разрешены ссылки на документацию и обезличенные или синтетические примеры запросов и ответов. Запрещены действующие URL порталов, ключи, реальные payload и данные клиентов.

Используйте первичные и официальные источники, добавляйте ссылки и дату проверки. Пароли, токены, вебхуки, персональные данные и клиентские выгрузки хранить запрещено.
