# Тесты

Назначение: хранение тест-кейсов, сценариев проверки и безопасных тестовых наборов.

Разрешены только обезличенные или синтетические данные. Реальные персональные данные, рабочие выгрузки и сведения действующих клиентов использовать запрещено, включая негативные сценарии и диагностические материалы.

Пароли, токены, вебхуки, персональные данные и клиентские выгрузки хранить запрещено.
