# Скрипты

Назначение: хранение вспомогательных скриптов автоматизации и интеграции, если они появятся в проекте.

Разрешены только поддерживаемые инструменты, использующие обезличенные или синтетические тестовые данные. Каждый скрипт должен поддерживать безопасный `dry-run`, явное логирование без чувствительных данных, обработку ошибок и проверку на ограниченной тестовой выборке до рабочего запуска.

Запрещены непроверенные массовые операции, встроенные секреты и рабочие клиентские данные. Пароли, токены, вебхуки, персональные данные и клиентские выгрузки хранить запрещено.
