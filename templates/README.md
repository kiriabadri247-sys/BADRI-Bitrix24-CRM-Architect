# Шаблоны

Назначение: хранение универсальных заготовок документов, настроек и рабочих материалов.

Разрешены только универсальные обезличенные шаблоны с синтетическими примерами. Запрещены адаптированные клиентские копии, реальные реквизиты и любые конфиденциальные сведения.

Пароли, токены, вебхуки, персональные данные и клиентские выгрузки хранить запрещено.
