# Диаграммы

Назначение: хранение схем архитектуры, процессов, данных и интеграций.

Разрешены только обезличенные схемы и синтетические примеры. Названия клиентов и сотрудников, домены, URL вебхуков, идентификаторы CRM и другие уникальные признаки необходимо заменять нейтральными обозначениями.

Запрещены рабочие снимки портала и схемы с конфиденциальными сведениями. Пароли, токены, вебхуки, персональные данные и клиентские выгрузки хранить запрещено.
