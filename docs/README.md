# Документация

Назначение: хранение архитектурных описаний, регламентов, инструкций и журналов изменений проекта.

Разрешено хранить только проверенные документы с обезличенными или синтетическими примерами. Запрещены клиентские выгрузки, рабочие копии документов и любые материалы с конфиденциальными сведениями.

Пароли, токены, вебхуки, персональные данные и клиентские выгрузки хранить запрещено.
